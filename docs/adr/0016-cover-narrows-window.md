# 0016. 開閉カバーは開口の倍率ではなく、窓孔の幅を変える

- 状態：提案（実装済み。聴いて確かめてから採用にする）
- 日付：2026-11-25

## 背景

聴き比べると、合成はまだ実機に及ばない。足りないものとして挙がったのは「レゾナンス感」「歪み」「フォルマント感」。

これまでの合成は、開閉カバーの開度 c を開口面積の倍率として扱っていた（`A = (leak + (1−leak)·c) × a(φ)`）。パルスの形 a(φ) は固定なので、カバーが動いても全部の倍音が同じだけ上下する。音色は、開き始めから止まるまで変わらない。

実機の開閉カバーは、固定カバーの窓孔の上を回って滑る板である（取扱説明書）。動くと変わるのは窓孔の幅で、パルスの幅が変わる。

## 決定

- 開口面積を「幅 `rotorWidth` の窓（羽根車）と、幅 `b = windowWidth × c` の窓（開閉カバーが残した窓孔）の重なり」にする。重なりは台形で、角を幅 `edgeBlur` の移動平均で丸める（`portArea`）。幅はどれもポートの間隔（1 周期）に対する比。
- 開閉カバーは片側から開くので、残る窓の中心は窓孔の中心から `(windowWidth − b)/2` ずれる。
- 閉じたカバーの漏れは、細い隙間ではなく、窓孔の全幅にわたる漏れにする（板と固定カバーの隙間）。`A = (1−leak)·W(rotorWidth, b) + leak·W(rotorWidth, windowWidth)`。
- `duty`・`edge` は廃止する。

| パラメータ | 値 | 意味 |
|---|---|---|
| rotorWidth | 0.115 | 羽根車の窓の幅 |
| windowWidth | 0.2 | 固定カバーの窓孔の幅（停止位置 0.9 で残る幅は 0.18） |
| edgeBlur | 0.08 | 縁のぼけ |
| leak | 0.075（旧 0.07） | 閉じたカバーからの漏れ（全幅） |

フォルマント（[0012](0012-fixed-formants.md)）、気流のノイズ、機構側（揺れ・圧の山）は変えない。

幅のモデルにした版を聴くと、変更前より実機に近づき、揺れ具合は肉薄した。上の倍音はまだ足りない。

- 上の倍音を測定に合わせて足す版（edgeBlur 0.03・ローパス 2500 Hz、下の「高次の倍音」）は、聴くと実機から離れ、音が潰れて聞こえたので**採らない**。測定した倍音の平均を合わせても、聴いた印象は良くならなかった。
- 細かい調整は、測定への当てはめではなく、画面のスライダーで聴きながら行う（`src/ui/tuning.ts`）。決まった値をここと既定値に戻す。

## 根拠

伊賀の映像（[0003](0003-iga-drive-from-video.md) と同じ）と、同じ時刻に同じ音を開いて書き出した合成を、同じ窓で比べた。

### 静的な倍音は、すでに音ごとのばらつきの範囲に入っている

保持音（2・3・5・6）の h2〜h8 は、変更前の合成でも「5」「6」「2」は実機と数 dB の差だった（「3」は実機のほうが h4〜h8 で 3〜11 dB 明るい）。h9 より上は足りない（下の「高次の倍音」）。

### 保持中、実機の倍音は基音と無関係に大きく揺れる

各倍音を複素復調（±40 Hz）して、保持中の振幅の揺れを測った（dB の標準偏差／3〜97% の幅）。

| | h1 | h2 | h3 | h4 | h5 | h8 |
|---|---|---|---|---|---|---|
| 実機「3」 | 1.1 / 3.7 | 3.1 / 10.8 | 3.5 / 13.7 | 1.7 / 6.2 | 3.7 / 14.2 | 5.8 / 21.5 |
| 実機「5」 | 1.5 / 5.2 | 2.0 / 8.0 | 5.0 / 19.5 | 2.5 / 8.8 | 3.7 / 13.8 | 4.9 / 15.9 |
| 変更前「5」 | 0.3 / 1.3 | 1.1 / 3.8 | 0.8 / 3.1 | 0.6 / 2.2 | 1.0 / 3.6 | 0.7 / 2.7 |
| 変更後「5」 | 0.3 / 1.3 | 1.1 / 3.9 | 1.0 / 3.7 | 1.3 / 4.9 | 4.3 / 17.6 | 0.9 / 3.2 |

実機は基音が安定しているのに、2 次以上が 8〜20 dB 動く。変更前の合成は全部の倍音が一緒に 1〜4 dB 動くだけだった（基音に対する傾きがどの倍音も約 1 dB/dB、相関 0.5〜0.9。実機は相関がほぼ 0 で符号もばらばら）。

### 立ち上がりで、高次の倍音は基音と逆向きに動く

実機の「5」（20.55 秒〜）の立ち上がり。h1 は定常に対する dB、ほかは h1 に対する dB。

| 時刻 | h1 | h3 | h5 | h6 | h8 | h12 |
|---|---|---|---|---|---|---|
| 0〜50 ms（開き始め） | −13〜−19 | −11〜−20 | −15〜−23 | −8〜−15 | −15〜−19 | −20〜−27 |
| 130〜180 ms（ストッパーに当たる山） | +2〜+4 | −20〜−43 | −27〜−36 | −33〜−46 | −32〜−47 | −32〜−51 |
| 200〜250 ms（跳ね返った谷） | −1〜−3 | −19〜−22 | −19〜−23 | −25〜−32 | −28〜−47 | −24〜−39 |

開き始めは倍音が多く、開ききると高次が 15〜30 dB 減り、跳ね返って少し閉じるとまた増える。開口の倍率が変わるだけなら、こうはならない。窓の幅 b が変わると、倍音は `sin(πh·rotorWidth)·sin(πh·b)/h` の形になり、谷（h = 1/b の倍数）が動くので、こうなる。

### 高次の倍音（試して採らなかった）

実機の倍音は h20（約 9 kHz）まで残る。基音に対する dB の平均（保持音、8192 点、倍音ごとに線の位置を探して測る。基音の位置の整数倍で読むと、高次は線から外れて弱く出る）。

| | 「3」h9〜15 | h16〜20 | 「5」h9〜15 | h16〜20 | 「6」h9〜15 | h16〜20 | 「2」h9〜15 | h16〜20 |
|---|---|---|---|---|---|---|---|---|
| 実機 | −24 | −33 | −36 | −40 | −34 | −42 | −32 | −38 |
| edgeBlur 0.08・5000 Hz | −38 | −43 | −47 | −49 | −48 | −53 | −38 | −45 |
| edgeBlur 0.03・2500 Hz（不採用） | −27 | −38 | −34 | −45 | −36 | −50 | −27 | −39 |

- 幅 0.08 の移動平均は倍音に sinc(0.08h) を掛ける。h9 で −10 dB、h12.5 に谷。これが高次を削っていた。0.03 なら h9 で −1 dB、谷は h33。
- 縁のぼけを小さくすると高次が出すぎるので、谷を作らない 1 次のローパスで全体の傾きを合わせた。2200〜2500 Hz なら [0012](0012-fixed-formants.md) の 4 音の h2〜h8 の誤差が 6 dB 以内に収まる（3000 Hz では「5」が 6.3 dB）。
- h16〜h17 に谷が残る（羽根車の幅 0.115 の谷 h8.7 の 2 倍と、窓 0.18 の谷 h5.6 の 3 倍が重なる）。実機には無い。窓が四角い穴だという単純化の限界。
- 羽根車の幅を 0.13〜0.14 にすると高次は合うが、h2〜h8 が 7〜10 dB に悪くなる。

### 幅の値

- 静的な倍音からは、2 つの幅の積の形（どちらが羽根車でどちらが窓孔かを入れ替えても同じ）しか決まらない。[0012](0012-fixed-formants.md) の 4 音の h2〜h8 に、フォルマントを変えずに当てはめると、停止位置で 0.105〜0.13 と 0.175〜0.18 に落ちる。縁のぼけは 0.03〜0.1 のどれでも h2〜h8 には同じくらい合う（音ごとの誤差 4.4〜5.4 dB。変更前の形は同じ測り方で 5.6 dB）。
- 開閉カバーが動かすほうを 0.18 にした。**仮定**。谷が低い倍音（h = 5.6）に来るので、揺れが聴こえやすい側である。逆（0.115 のほうが動く）なら谷は h = 8.7 に来る。
- 音ごとに幅を自由にすると、フォルマント無しでも 4.8 dB まで合う（「2」0.28、「3」0.155、「5」0.43、「6」0.5）。ただし 4 音に 4 つの自由度なので、当てにならない。停止位置の個体差は入れていない。

### 漏れは全幅

全閉の区間（14.5〜17.0 秒）の漏れ音と、同じサイレンが開いたときの倍音を比べた。他の音と重ならず、雑音より 6 dB 以上高い倍音だけを使うと、「3」「6」「2」では漏れ音の倍音の形は開いた音と ±8 dB で同じで、明るくはない（「5」だけは漏れ音のほうが明るい）。細い隙間（幅 leak × windowWidth）にすると、漏れ音の h5〜h8 が基音と同じくらいになり、実機より 10〜20 dB 明るすぎた。

### 固定の周波数特性を、惰性の掃引から測った（参考）

電源断のあとの惰性（40.6〜64.3 秒、回転数比 0.98 → 0.56）では、8 音の漏れ音と倍音がそれぞれ 0.8 オクターブ掃引する。`log A[k,h](t) = S[k,h] + g(t) + H(h·f_k·r(t))` を最小二乗で解くと、線ごとの大きさ S と自動利得 g(t) を除いた H(f) が出る（対数周波数に対する傾きは決まらない）。

- 500〜850 Hz に +3〜6 dB の広い山、1.1〜1.7 kHz に −3〜−4 dB の浅い谷、3.0〜3.2 kHz と 4.3 kHz に +3〜4 dB の山。起動の掃引（8.3〜13.4 秒）でもほぼ同じ形。
- 山と谷の位置は [0012](0012-fixed-formants.md) と合う。深さはずっと浅い（0012 は +18 dB と −30 dB）。漏れ音の経路と開いた音の経路が違うのか、0012 の当てはめが音源の形の違いをフォルマントに押し込んでいるのかは、分からない。フォルマントは今回は変えない。

### 軸の回転数の側帯波（参考）

保持音のまわりに、軸の回転数（「3」は 44.3 Hz、「5」は 59.0 Hz）の倍数の線がある。他の音の漏れ音と重ならないものは、基音に対して −19〜−36 dB。窓の不ぞろい・偏心で、1 回転ごとに音が変調されている。合成には無い。

## 結果

- `src/audio/synth.ts`：`portOpening`・`duty`・`edge` を `portArea`・`rotorWidth`・`windowWidth`・`edgeBlur` に置き換えた。
- 音色のパラメータは鳴らしながら差し替えられる（`SirenSynth.setParams`、Worklet の `params` メッセージ、`AudioEngine.setSynthParams`）。画面の「音の調整」に、合成と開閉カバーのパラメータのスライダーを置いた（`src/ui/tuning.ts`）。値はブラウザに保存し、既定値との差分を JSON でコピーできる。利得 0 dB の 3 つめのフォルマントを試せる。
- `src/audio/synth.test.ts`：台形の形と、ぼかしても面積が変わらないこと、開き始めは高次の倍音が多いこと、漏れ音の倍音の形は重なりきった音と同じこと、カバーが揺れると基音より高次が大きく動くことを足した。倍音・フォルマントのテストは、カバーを停止位置（0.9）にして測るようにした。
- 変更後の合成：立ち上がりで h5〜h8 が −14〜−18 dB → −28〜−35 dB と減り、揺れの間 h6 が −28〜−50 dB を行き来する。全閉の漏れ音と保持音の大きさは変更前と 1〜2 dB の差。
- 残った課題：
  - 保持中の揺れは、谷に近い倍音（h5）だけが実機なみになった。実機はどの倍音も基音と無関係に揺れる。開閉カバーの揺れだけでは足りない。撮影位置の動き・反射の干渉の可能性もある。
  - 軸の回転数の側帯波（窓の不ぞろい）は入れていない。「歪み」の候補。
  - 上の倍音（h9〜h20）が足りない。縁のぼけを減らす方法は聴いて不採用。別の足し方を聴きながら探す。
  - 実機の雑音の床は 9 kHz までほぼ平らで、合成は高域が落ちる（`jetCutoffHz` 2000 Hz、[0006](0006-jet-noise-and-headroom.md) で聴いて決めた値）。
  - 3 kHz・4.3 kHz の山、フォルマントの深さの見直し。
  - 開閉カバーの揺れ（[0009](0009-cover-stopper.md)・[0010](0010-milder-cover-bounce.md)）は、開口の倍率として基音の包絡に当てはめた値のまま。幅のモデルで当てはめ直していない。
