# 0004. 伊賀機の音の既定値を映像から決める

- 状態：採用（jet・gain は [0006](0006-jet-noise-and-headroom.md)、duty・edge・radiationCutoffHz は [0012](0012-fixed-formants.md)、閉じる時間は [0014](0014-cover-close-and-no-residual-pressure.md) で置き換え）
- 日付：2026-11-22

## 背景

合成（`src/audio/synth.ts`）の既定値は、岡山県庁の録音で決めていた。この録音は平均律の 17 音以上で、第2世代の可能性が高い。伊賀機に絞った（[0001](0001-model-iga-only.md)）ので、伊賀機の映像（[0003](0003-iga-drive-from-video.md) と同じもの）で決め直す。

## 決定

| パラメータ | 旧 | 新 | 意味 |
|---|---|---|---|
| duty | 0.46 | 0.315 | 開口関数（台形）の半値幅（周期比） |
| edge | 0.16 | 0.16 | 開口関数の縁の幅 |
| radiationCutoffHz | 600 | 300 | 放射のローパス |
| leak | 0.03 | 0.11 | 閉じたカバーからの漏れ（開口比）。約 −19 dB |
| jet | ― | 0.8 | 窓孔を抜ける気流のノイズ（新設） |
| gain | 0.25 | 0.42 | 旧設定と同じくらいの音量になるよう補正 |

開閉カバーの時間（開 80 ms・閉 120 ms）は据え置き、最短の開閉間隔 1/3 秒を足す（[0005](0005-ymsha-advice.md)）。

## 根拠

測定は、映像の定常区間（14.5〜17.6 秒は全カバー閉、17.8〜39.4 秒は演奏）で行った。

### 倍音

よく鳴っている「3」（27.6〜30.4 秒）と「5」（20.6〜22.0 秒）の、基音に対する dB。

| | h2 | h3 | h4 | h5 | h6 | h7 | h8 |
|---|---|---|---|---|---|---|---|
| 3 | −3.2 | −21.5 | −12.9 | −14.4 | −26.2 | −21.4 | −23.1 |
| 5 | −11.7 | −24.2 | −22.7 | −25.6 | −36.8 | −40.2 | −42.1 |
| 平均（目標） | −7.5 | −23 | −18 | −20 | −31.5 | −31 | −33 |

h3 と h6 が隣より弱い。これは開口の半値幅が周期の約 1/3 のときに出る形である。台形の開口関数＋微分＋1次ローパスで当てはめると、duty 0.315・edge 0.16 になった。ローパスは低いほど合う（50 Hz で誤差平方和 13.6、300 Hz で 26.3、600 Hz で 69.8）。ただし低くしすぎると起動中の音量の変わり方が不自然になるので、300 Hz にした。300 Hz での各倍音の誤差は 2 dB 程度。

録音の位置は機械の端に近く、サイレンごとに距離が違う。そのため、音による倍音の差（3 の h2 が強いなど）は距離と共鳴の影響も含む。既定値には平均を使う。

### 漏れ

全カバー閉の区間に、8 音すべての線が出ている。演奏で開いた音の上がり幅は「5」が +13.2 dB、「3」が +9.5 dB だった。ただし開いた瞬間に、他の音の線が 7〜8 dB 下がる。カメラの自動利得と考え、その分を補正すると、漏れは全開に対して −21.5 dB（5）、−16.8 dB（3）。平均 −19 dB から leak = 0.11。岡山の値（−20〜−25 dB）とも近い。

### 気流のノイズ

全開の音が鳴っている間は、線と線の間の広帯域ノイズが上がる。全閉の区間と比べ、自動利得を補正して 300 Hz〜5 kHz で +5〜16 dB。全開の「5」の音と、そのまわりのノイズ（5.4 Hz 幅あたり）の差は 31.6 dB。

旧モデルのノイズは半開きのときだけ出していたので、これを再現できなかった。窓孔を抜ける噴流の乱流として、開口面積 × 回転数² に比例するノイズを足した（`jet`）。ノイズも開口面積で変調されるので、基音のまわりに裾が広がる。これはスペクトログラムで開いた音のまわりに見える毛羽立ちに当たる。jet = 0.8 で、音とノイズの差が約 32 dB になる。

### 開閉の時間

基音振幅の 10→90% が 58〜93 ms、90→10% が 64〜142 ms（4 音の中央値）。岡山（45〜130 / 45〜160 ms）と同じ範囲なので、開 80 ms・閉 120 ms を据え置く。

## 結果

- `src/audio/synth.ts`：上の既定値と、`jet`（気流のノイズ）を追加した。
- `src/audio/synth.test.ts`：倍音（目標の ±4 dB、h3 < h4・h6 < h5）、漏れ（−17〜−22 dB）、気流のノイズ（音との差 28〜36 dB、閉じると 12 dB 以上下がる）をテストで固定した。
- 残った課題：
  - 演奏中に他の音の線が下がるのは、カメラの自動利得と考えて補正した。実機の現象（開いたカバーの分だけ他のサイレンの圧が下がる、など）の可能性は確かめていない。
  - サイレンごとの距離と共鳴の違い（音色の個体差）は入れていない。
  - 残圧による余韻、固定共鳴、距離表現は未着手（v1 の移植の候補）。
