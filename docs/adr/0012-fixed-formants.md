# 0012. 固定の共鳴（フォルマント）を入れる

- 状態：採用（[0004](0004-iga-sound-from-video.md) の duty・edge・radiationCutoffHz と、[0006](0006-jet-noise-and-headroom.md) の jet を置き換え）
- 日付：2026-11-22

## 背景

聴くと「フォルマントがない」。これまでの合成（台形の開口 → 流量の微分 → 1 次ローパス）では、倍音の比が基音について決まっていた。そのため音程を変えると、スペクトルの形もそのまま平行移動する。音程によらず同じ周波数に居座る山や谷がなく、どの音も同じ音色になっていた。

[0004](0004-iga-sound-from-video.md) の当てはめは、「3」と「5」の倍音を基音で割って平均したものだった。音による違い（「3」の h2 が強いなど）は、距離と共鳴の影響として捨てていた。

## 決定

- 全サイレンの音の和に、固定のピーキング・フィルタ（RBJ）を 2 段、直列に掛ける（`SynthConfig.formants`）。
  - 共鳴：580 Hz、+18 dB、Q 3
  - 反共鳴：1300 Hz、−30 dB、Q 1
- 音源はフォルマントと一緒に当てはめ直す。

| パラメータ | 旧 | 新 |
|---|---|---|
| duty | 0.315 | 0.175 |
| edge | 0.16 | 0.175 |
| radiationCutoffHz | 300 | 5000（高域の減り方はフォルマントが受け持つ） |
| jet | 0.28 | 0.58（ノイズの総量を 8 音の平均で −18 dB に保つ） |
| gain | 0.12 | 0.12（据え置き） |

- 気流のノイズにはフォルマントを掛けない。

## 根拠

伊賀の映像（[0003](0003-iga-drive-from-video.md) と同じ）の演奏区間（17.8〜39.4 秒）から、1 音だけが開いているフレームを選んだ。基音の線が、全閉の区間（14.5〜17.6 秒）より 10 dB 以上高いことを条件にした。単音で十分に鳴っていたのは「2」「3」「5」「6」の 4 音（79〜244 フレーム）。各音の h1〜h16（7 kHz まで）の中央値を取った。

### 基音に対する倍音（dB）

| | f₀ | h2 | h3 | h4 | h5 | h6 | h7 | h8 |
|---|---|---|---|---|---|---|---|---|
| 2 | 400 | +0.6 | −18.4 | −19.7 | −23.6 | −26.6 | −18.3 | −22.1 |
| 3 | 444 | −5.0 | −21.9 | −14.1 | −17.4 | −24.9 | −26.2 | −23.0 |
| 5 | 533 | −12.6 | −25.7 | −24.6 | −30.4 | −35.3 | −38.0 | −32.5 |
| 6 | 592 | −32.9 | −15.6 | −28.8 | −22.1 | −35.5 | −30.6 | −35.2 |

倍音の番号で見るとばらばらで、絶対周波数で見ると揃う。

- 「6」の h2（1184 Hz）は −33 dB と極端に弱く、「5」の h2（1066 Hz）も弱い。「2」の h3（1200 Hz）、「3」の h3（1332 Hz）も隣より弱い。→ **1200〜1300 Hz に谷**。
- 「2」の h2（800 Hz）は基音と同じくらい強い。
- 「6」の h3（1776 Hz）と「3」の h4（1776 Hz）は、どちらも隣より強い。
- [0004](0004-iga-sound-from-video.md) では「h3 と h6 が弱いのは開口の半値幅が約 1/3 だから」と読んだ。しかし「6」では h3 が h2 や h4 より強く、この読みと合わない。

### 当てはめ

モデルは「音源（台形の開口・微分・ローパス）＋フォルマント＋音ごとの音量（距離の差を吸収）」とし、dB の最小二乗で当てはめた。誤差（rms, dB）は次のとおり。交差検定は、1 音を外して残り 3 音で当てはめ、外した音を予測させた値。

| モデル | 全体の当てはめ | 交差検定 |
|---|---|---|
| 旧（duty 0.315・edge 0.16・300 Hz、フォルマントなし） | 11.4 | ― |
| 音源だけを当てはめ直す | 5.8 | 6.4 |
| 音源＋ピーキング 2 段 | 3.2〜3.9 | 3.8 |

- 音源だけでは、どう当てはめても 5.8 dB より良くならない。2 段のフォルマントを足すと、外した音の予測でも 3.8 dB まで下がる。
- 当てはめのたびに、山は 570〜580 Hz、谷は 1250〜1340 Hz に落ちた。
- 自由な形の周波数特性（1/4 オクターブごと）で当てはめても、同じ形になった。500〜700 Hz が最も高く、1200〜1400 Hz が最も低く（約 −19 dB）、2 kHz 付近で戻る。
- 基音の大きさも合う。映像では「5」「6」が「2」「3」より 5〜6 dB 大きい。モデルでは 6〜10 dB 大きい（「6」は 4.5 dB ほど大きめ）。
- 採用した値（丸めたもの）での全体の誤差は 4.0 dB。音ごとの h2〜h8 の誤差は 4.1〜5.9 dB。

### 気流のノイズに掛けない理由

フォルマントをノイズにも掛けると、1〜2 kHz のノイズがほぼ消える。ところが映像のノイズ（[0006](0006-jet-noise-and-headroom.md) の表）では、1k〜2k の帯域が −19.8 dB（「5」）・−18.3 dB（「3」）で、隣の帯域と変わらない。そこでノイズには掛けない。

## 結果

- `src/audio/synth.ts`：`Formant`・`formants`・`peakingCoefficients` を追加し、音の和にフィルタを掛けるようにした。既定値を上の表に合わせた。
- `src/audio/synth.test.ts`：
  - 旧い倍音のテスト（480 Hz の 1 音で h2〜h6 の ±4 dB、h3 < h4・h6 < h5）は外した。
  - 映像の 4 音それぞれの h2〜h8 の誤差（rms 6 dB 以内）をテストにした。
  - 「6」の h2 が弱く（< −20 dB）、「2」の h2 が強い（> −8 dB）ことをテストにした。
  - 「5」「6」の基音が「2」「3」より 3〜10 dB 大きいことをテストにした。
  - ノイズの総量のテストは、9 ポートの 1 音ではなく 8 音の平均にした。
- 単音の全開の大きさは、音によって −13〜−23 dBFS になった（旧は −18〜−23）。「6」が最も大きく、「i」が最も小さい。4 音の和音のピークは 0.59。
- 残った課題：
  - **共鳴の出どころは決めていない。** 候補は、サイレン本体の空気室・建屋・撮影位置での反射。1300 Hz の谷のほか、3.3〜4 kHz と 5.6〜6.7 kHz にもわずかな谷がある。もし谷が 1300 Hz の奇数倍に並ぶのなら、経路差約 14 cm の反射による櫛形フィルタかもしれない。その場合は機械の音色ではなく、聞く位置で決まる性質になる。これは伊賀の映像 1 本だけでは区別できない。
  - 単音で十分に鳴っていない「1」「4」「7」「i」は確かめていない。
  - 10B の「ふるさと」の録音では、この山と谷は再現しなかった（[0013](0013-furusato-10b-recording.md)）。伊賀機だけの既定値として扱う。
  - 聴いた印象での微調整は、[0010](0010-milder-cover-bounce.md) と同じく別の ADR にする。
