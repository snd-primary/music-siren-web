# 0007. サイレンごとのゆらぎ（うなり）を劣化度として入れる

- 状態：置き換え：[0008](0008-cover-bounce.md)
- 日付：2026-11-22

## 背景

[0006](0006-jet-noise-and-headroom.md) のあとで聴くと、実物の音はもっとピアニカのようで、うなりがある、という所見があった。ユーザーの見立ては、うなりは開閉が不安定なことから生じていて、劣化具合によって変わるものではないか、というものだった。

合成はサイレンごとに完全に一定の音を出しており、ゆらぎは無かった。

## 決定

- 各サイレンの開口に、ゆっくりした乱数の揺れを掛ける。
  - 振幅：全開で相対 10%、閉じているとき（漏れ音）で 18%。開度に応じて線形に変える。
  - 形：開口関数の縁の幅（edge）を相対 35% 揺らす。倍音が基音より大きく揺れる。
- 揺れはサイレンごとに独立にする。周期 0.4 秒の遅い層と、周期 0.1 秒・重み 0.35 の速い層を重ねたバリューノイズにする。
- 深さはまとめて **劣化度 `wear`** に掛ける。0 は新品（揺れない）、1 は伊賀機の映像の状態で、既定は 1。

これは、開閉カバーの座りの悪さ（劣化）が揺れの原因だという仮説に立つ。

## 根拠

伊賀の映像の持続音（「5」20.6〜22.0 秒、「3」27.6〜30.4 秒・36.9〜39.1 秒）と、全閉の区間（14.6〜17.6 秒）の漏れ音で測った。基音のまわり ±12〜20 Hz を帯域通過し、ヒルベルト変換で包絡と瞬時周波数を出した。

| | 振幅の揺れ（std/mean） | 主な周波数 | 周波数の揺れ |
|---|---|---|---|
| 全開の基音 | 0.07〜0.18 | 3 Hz 未満が主、3〜10 Hz が少し | 0.9〜2.8 セント |
| 全開の 2〜3 次倍音 | 0.20〜0.43 | 同上 | ― |
| 閉じた漏れ音（5 音） | 0.20〜0.31 | 3 Hz 未満が主 | 1.0〜2.8 セント |

- **サイレン同士の相関はほぼ 0。** 8 音の包絡（対数、0.3〜10 Hz）の相関の平均は、全閉で −0.04、「3」全開で 0.00、「5」全開で −0.02 だった。カメラの自動利得や風なら全音が一緒に揺れるので、これらではない。サイレンごとの原因と考えられる。
- 閉じた漏れ音は、相対的に開いた音の約 2 倍揺れる。開いているときはマグネットがレバーをストッパーに押し付けているので、閉じているとき（スプリングだけで戻した位置）より座りが安定する、という見立てと合う。ただし漏れ音は小さいので、測定値には録音のノイズの分も入っている。そこで既定値は実測の下限寄りにした（18%）。
- 「3」の瞬時周波数に 29.6 Hz の成分があった。これは隣の「4」の漏れ音（473.7 Hz）との差音で、揺れではない。全サイレンの漏れ音を合成しているので、この差音は合成でも出る。
- 開口の形の揺れを duty に掛けると、3 次倍音だけが極端に揺れた（duty ≈ 1/3 は h3 の零点の近くにあるため）。そこで edge に掛けた。合成での揺れ（20 秒の平均）は、全開で h1 約 0.10・h2 0.10・h3 0.18・h4 0.29、全閉で h1 約 0.18。h2 は形をどう揺らしてもあまり動かず、実測（0.20〜0.43）より小さい。

## 結果

- `src/audio/synth.ts`：`Flutter`（バリューノイズ）と、`wear`・`flutterOpen`・`flutterClosed`・`flutterShape` を追加した。
- `src/audio/synth.test.ts`：全開の揺れ（6〜16%）、漏れ音の揺れ（14〜30%、全開より大きい）、3 次倍音は基音の 1.5 倍以上揺れること、サイレン同士の相関（|r| < 0.3）、wear = 0 で揺れないことをテストした。静的な倍音構造と漏れのテストは wear = 0 で測る。
- 残った課題：
  - 揺れの原因（カバーの座りの悪さか、空気路ごとの流れの乱れか）は、この映像だけでは区別できない。
  - 劣化が進むと漏れ（leak）も増えるはず（説明書：レバーの停止位置が悪いと音が出放しになる）。wear と leak を結び付けるかは未定。
  - 「ピアニカっぽさ」の音色そのもの（リードのような倍音の立ち方）は、揺れ以外に原因があるかもしれない。聴いて確かめる。
  - 周波数の揺れ（1〜3 セント）は入れていない。全サイレンが歯車で剛結されているので、入れるなら軸ごとの共通の揺れになる。
