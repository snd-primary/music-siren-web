# 0008. ゆらぎを開閉カバーの揺れとして機構側に入れる

- 状態：採用（[0007](0007-flutter-from-wear.md) を置き換え）
- 日付：2026-11-22

## 背景

[0007](0007-flutter-from-wear.md) では、合成側でサイレンごとに乱数の揺れを掛けた。聴くと、閉じている（開いていない）サイレンの漏れ音まで揺れて騒がしかった。

ユーザーから、再現したい揺れの整理があった。

- ダンパー（開閉カバー）が回り、その開口が固定カバーのポートと重なったときに発音する。
- このとき、ダンパーがポートの位置でピタッと止まらずに生じる揺れを再現する。

つまり揺れは開閉カバーの動きそのものである。設計方針（音と見た目を同じ機構モデルから導く）に従い、合成ではなく機構側に置く。

## 決定

### 開閉カバーの動き（`src/mechanism/simulation.ts`）

- カバーの角度 θ を状態に持つ。0 = 閉、1 = 開閉カバーの窓と固定カバーのポートがぴったり重なる位置。
- 窓孔の重なり（開度）は `1 − |1 − θ|`。重なりきる位置を行き過ぎると、また減る。
- マグネットが引くと、θ は停止位置 `restAngle = 0.8` へ向かう 2 次の振動になる（`bounceHz = 8`、`bounceDamping = 0.22`）。停止位置は重なりきる位置より手前にある。そのため揺れの山で重なりきる位置を通り、開いた直後に音が大きくなったり小さくなったりする。
- 開いている間も、停止位置がゆっくりずれる（`wander = 0.05`、座りの悪さ）。ずれはサイレンごと・開いてからの時刻ごとに決まる純粋関数で、周期 0.4 秒の層と、周期 0.1 秒・重み 0.35 の層を重ねる。
- 通電を切ると、スプリングで一定速度（`closeTime = 0.12` s）で戻り、ストッパーで止まる。**閉じている間は揺れない。**
- 3D の開閉カバーは、この角度 θ で回る（行き過ぎも見える）。

### 空気室の圧の山（surge）

- 閉じている間に羽根車が空気室の圧を上げ、開いた瞬間に抜ける。流量の倍率 `1 + surge` として合成に渡す。
- 値は `surge = 0.4`、開いて抜ける時定数 0.3 秒、閉じてたまる時定数 0.15 秒。

### 合成（`src/audio/synth.ts`）

- 0007 の揺れ（`Flutter`、`wear`、`flutterOpen`・`flutterClosed`・`flutterShape`）を外した。
- 半開きのときのノイズ（`noise`）も外した。カバーは重なり 0.8 で止まるので、残すと開いている間ずっと「かすれ」が鳴る。気流のノイズ（`jet`）が開口に比例して出るので、その役目は jet が担う。
- 漏れ（leak）を 0.11 から 0.07 にした。閉じている間は圧がたまって漏れ音が大きくなり（×1.4）、開いても重なりは 0.8 なので、その分を見込んで、閉じた音が開いた音より約 19 dB 低くなるよう合わせた。
- カバーの開度の補間を 3 ms から 6 ms にした。約 8 Hz の揺れは通し、約 60 Hz の更新の段差だけをならす。

## 根拠

伊賀の映像で、音の立ち上がりの包絡（基音 ±15 Hz の帯域通過＋ヒルベルト変換、2 ms ごと）を、開いて 0.35〜0.6 秒後の定常の大きさで割って並べた。きれいに取れた 9 回（「3」4 回、「5」4 回、「6」1 回）の中央値（半分まで立ち上がった時刻の 20 ms 前から、20 ms ごと）：

```
データ  0.04 0.53 1.21 1.54 1.45 1.28 1.15 1.16 1.09 1.36 1.59 1.38 1.13 1.09 1.05 1.12 1.18 1.24 1.09 1.04 1.02
モデル  0.01 0.50 1.22 1.31 1.44 1.21 0.96 0.97 1.14 1.26 1.26 1.17 1.08 1.06 1.08 1.11 1.11 1.09 1.07 1.05 1.05
```

モデルの行は、機構と合成をつなぎ、画面と同じ約 60 Hz で状態を渡して計算した（停止位置のずれは 0）。

- 10→90% の立ち上がりは 6〜20 ms と速い。最初の山（定常の 1.2〜1.6 倍）は 40〜55 ms、谷は 110〜135 ms、2 回目の山は 160〜180 ms で、250〜400 ms で収まる。→ 約 7〜8 Hz の揺れ。
- 山は定常より大きい。これは、マグネットで引いて止まる位置が重なりきる位置より手前にあり、揺れの途中で重なりきる位置を通るからと読む。
- 谷も定常の約 1.1 倍あり、揺れの土台そのものが開いた直後に高く、数百 ms かけて下がる。カバーの揺れだけでは説明できないので、空気室にたまった圧が抜ける効果を分けて入れた。
- 1 回ずつ当てはめた値は揃っていた。停止位置 0.75〜0.85、揺れ 7〜8.5 Hz、減衰比 0.19〜0.29、圧の山 0.3〜0.46、抜ける時定数 0.25〜0.4 秒。
- 開いている間のゆっくりした揺れ（[0007](0007-flutter-from-wear.md) の根拠：全開の基音で 7〜18%、サイレン同士の相関ほぼ 0）は、停止位置のずれとして入れた（合成した開度の相対の揺れ 3〜12%）。

## 結果

- `src/mechanism/simulation.ts`：状態に `coverAngles`・`coverVelocities`・`surges` を足した。`covers` は窓孔の重なり（音が読む）になった。`CoverParams` から `openTime` を外し、`restAngle`・`bounceHz`・`bounceDamping`・`wander`・`surge`・`surgeReleaseSec`・`surgeFillSec` を足した。
- `src/audio/synth.ts`・`engine.ts`：`SynthTarget.surges` を受け取る。揺れと半開きのノイズを外した。
- `src/scene/scene.ts`：開閉カバーは `coverAngles` で回る。
- テスト：立ち上がりの速さ、最初の山（定常の 1.15〜1.3 倍、30〜80 ms）、揺れの周期（7〜9 Hz）と 0.4 秒で ±3% に収まること、開いている間の揺れ（3〜12%）、閉じると揺れないこと、圧のたまり方と抜け方、surge の分だけ音が大きくなること、漏れ（−17〜−22 dB）。
- 残った課題：
  - データの 2 回目の山（1.59）が、モデル（1.26）より大きい。線形の振動では 1 回目と同じ高さの 2 回目の山は出ない。レバーがストッパーに当たって跳ね返る、のような非線形の動きかもしれない。
  - 圧の山は、カバーの揺れと分けて当てはめただけで、空気室の容積などからは導いていない。v1 の「残圧による余韻」（閉じたあとに鳴り続ける）とあわせて、空気室のモデルとして整理する余地がある。
