## 書式

```markdown
# 00xx. 題

- 状態：提案 / 採用 / 置き換え：00yy / 廃止
- 日付：YYYY-MM-DD

## 背景
なぜ決める必要があったか。前提、手元の資料、制約。

## 決定
何を決めたか。

## 根拠
資料・測定・計算。数値は出典と一緒に。

## 結果
この決定で何が変わるか。コードの場所、テスト、残った課題。
```
