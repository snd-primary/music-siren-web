# 0005. YMSHA の助言を機構の前提にする

- 状態：採用
- 日付：2026-11-22

## 背景

説明書だけでは決まらない点が残っていた。ポート数は羽根数なのか窓数なのか、羽根の形状、開閉カバーの動作の限界、停止時間の実態である。参考資料の YMSHA のメンバーから、次の助言を受けた。

- ポート数は羽車、シャッターなどどれも同じ数です。
- 羽の形状は第2図通りです。
- 開閉は一秒2～3回までと考えるといいです。
- 停止時間は劣化具合によります。

## 決定

1. **羽根車の羽根数・固定カバーの窓数・開閉カバーの窓数は、どれもポート数に等しい** ものとする。未確定から外す。
2. **羽根の形状は説明書の第2図に従う。** 3D で羽根を詳しく作るときは第2図の比率を使う（図面のトレースはしない）。
3. **開閉は 1 秒に 3 回まで** とする。開閉カバーは、前に開き始めてから 1/3 秒経つまで次を開き始めない（`CoverParams.minCycle`）。それより速い連打は遅れるか落ちる。
4. **停止時間は個体のブレーキの劣化具合で決まる** ものとする。説明書の「8〜10 秒」は新品の値と読み、既定値は伊賀機の映像の実測にする（[0003](0003-iga-drive-from-video.md)）。`brakeTorque` は劣化具合のパラメータとして扱う。

## 根拠

- 1：音程式「ポート数 × 軸回転数」は 5 機種の配列表すべてと一致している。羽根と窓が同数なら、1 回転で開閉がポート数回起きる。助言はこれと矛盾しない。
- 3：マグネットがレバーを引き、スプリングで戻す機構の往復の限界。伊賀の映像の家路では、同じ音の開き直しの最短間隔はこれより長い。
- 4：伊賀機の映像では、電源断から 24 秒で同期回転数の 56% までしか下がらない。減速は空気負荷だけでほぼ説明できる（[0003](0003-iga-drive-from-video.md)）。

## 結果

- `src/mechanism/simulation.ts`：`CoverParams.minCycle`（既定 1/3 秒）と、状態 `coverPulled`・`sinceOpen` を追加した。
- `src/mechanism/simulation.test.ts`：開き直しの遅れと、4 Hz の連打が 3 回までに制限されることをテストした。
- `src/mechanism/cam.test.ts`：収録曲が伊賀機で同じサイレンを 1/3 秒より短い間隔で開き直さないことをテストした。
- `src/scene/scene.ts` はすでに羽根数＝窓数＝ポート数で描いているので、変更は無い。
- 残った課題：開閉カバーの回転角、羽根と窓の寸法（第2図の比率から拾う）。
