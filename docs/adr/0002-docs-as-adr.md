# 0002. ドキュメントは ADR で書く

- 状態：採用
- 日付：2026-11-22

## 背景

これまでの調査メモ（`docs/music-siren-project.md`）は 1 ファイルに追記を重ねてきた。そのため、どの値をいつ・何を根拠に決めたかが追いにくい。前提が後から覆ることも多い（説明書の「起動 10〜15 秒」の解釈、ブレーキの停止時間、どの機体を基準にするかなど）。

## 決定

これからのドキュメントは ADR（Architecture Decision Record）で書く。

- 置き場所は `docs/adr/`。ファイル名は `NNNN-題.md`（番号は 4 桁の通し番号）。
- 書式と一覧は `docs/adr/README.md` に置く。
- 決定を覆すときは古い ADR を書き換えない。新しい ADR を書き、古いほうの状態を「置き換え：NNNN」にする。
- 測定や解析の所見は、それを使った決定の ADR の「根拠」に書く。
- `CLAUDE.md` は Claude Code が読む設定ファイルなので、ADR にはせず Markdown のまま保つ。内容は ADR に合わせて更新する。
- 既存の `docs/music-siren-project.md` と `docs/handoff-*.md` は、ADR 以前の文書として残す。

## 結果

- `docs/adr/` を作り、0001〜0005 を書いた。
- コード中の根拠コメントは、該当する ADR を指す。
