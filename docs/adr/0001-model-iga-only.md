# 0001. 初段のモデリング対象を伊賀機 1 台に絞る

- 状態：採用
- 日付：2026-11-22

## 背景

配列表の 5 機種（8音伊賀・10A・10B・12A・12C）を音程式で扱えるようになった。ただし、音程以外の値（滑り、起動・停止、開閉、倍音、漏れ）は、機種ごとの資料が無いまま共通の値にしていた。どの機種も広く浅い状態だった。

初段では 1 台に絞り、その 1 台を根拠のある値だけで固めたい。候補は手元に資料がある 2 台だった。

- **伊賀機**（伊賀市・1982 年・8音 350φ・60Hz・市指定文化財）
- **トキハ本店**（大分・10B・露天）

最初はトキハを推した。伊賀機の録音が無いと考えていたからである。ところが `doc/` に伊賀機の映像（YouTube「伊賀市に現存するミュージックサイレンを間近で聞かせて頂きました」、70 秒）があり、前回の引き継ぎで見落としていたとわかった。

## 決定

初段のモデリング対象は **伊賀機 1 台** とする。精緻にする範囲は **駆動（起動・停止）と音（合成）**。3D の外観は後回しにする。

他の 4 機種のプリセットと選択 UI は残す（消さない）。ただし既定値は伊賀機に合わせ、他機種には当てはめない。

## 根拠

| | 伊賀機 | トキハ 10B |
|---|---|---|
| 起動 | 映像にある（約 12 秒） | 映像にある（約 5 秒） |
| 停止 | **映像にある**（電源断から 30 秒の惰性） | 映像に無い |
| 演奏 | 近い距離で 22 秒（家路） | ニュース映像で 28 秒 |
| 寸法 | 説明書の 8音 350φ の基礎寸法と、実機の本体・建屋の寸法が一致する | 説明書の 10音AB の寸法だけ |
| 立場 | CLAUDE.md の基準機 | 現役の商業施設の機械 |

駆動と音のどちらも、伊賀機のほうが 1 本の映像で検証できる範囲が広い。

## 結果

- 駆動系の既定値を伊賀機の映像に当てはめ直した（[0003](0003-iga-drive-from-video.md)）。
- 合成の既定値を伊賀機の映像に合わせた（[0004](0004-iga-sound-from-video.md)）。
- トキハの当てはめは `TOKIWA_10B_DRIVE_PARAMS` として残した。
