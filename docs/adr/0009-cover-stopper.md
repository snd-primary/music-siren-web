# 0009. 開閉カバーの揺れにストッパーの跳ね返りを入れる

- 状態：採用（[0008](0008-cover-bounce.md) のカバーの動きと値を置き換え）。restAngle・bounceDamping・wander は [0010](0010-milder-cover-bounce.md) で置き換え
- 日付：2026-11-22

## 背景

[0008](0008-cover-bounce.md) では、開閉カバーの角度を停止位置のまわりの線形の 2 次振動にした。開いた直後の 2 回目の山は、映像の 1.59 に対してモデルが 1.26 で、小さかった。線形の振動では、1 回目と同じくらいの高さの 2 回目の山は出ない。

## 決定

- 重なりきる位置（θ = 1）に **ストッパー** を置く。カバーはそれより先へ行かず、当たると反発係数 `stopRestitution` で跳ね返る。
- 開度は `1 − |1 − θ|` から `θ` に変えた（θ ≤ 1 なので、行き過ぎて重なりが減ることはもう無い）。
- 値は長く保持された音の立ち上がり 7 回（0.9 秒分）の中央値に当てはめ直した。

| パラメータ | 0008 | 新 |
|---|---|---|
| restAngle | 0.8 | 0.85 |
| bounceHz | 8 | 6.45 |
| bounceDamping | 0.22 | 0.094 |
| stopRestitution | ― | 0.235 |
| surge | 0.4 | 0.5 |
| surgeReleaseSec | 0.3 | 0.29 |

leak（0.07）は、新しい停止位置と圧の山で計算し直すと 0.069 なので据え置いた。

## 根拠

伊賀の映像で、0.9 秒以上保持された音の立ち上がり 7 回（「3」4 回、「5」2 回、「6」1 回）を、開いて 0.6〜0.9 秒後の定常で割って中央値を取った。40 ms ごと（半分まで立ち上がった時刻の 20 ms 前から）：

```
データ  0.07 1.11 1.30 1.13 1.36 1.65 1.09 1.12 1.22 1.19 1.08 1.12 1.05 0.99 0.95 1.09 1.11 1.02 0.99 1.07 1.02 0.95 0.99
モデル  0.03 1.28 1.18 1.12 1.40 1.34 1.10 1.10 1.22 1.16 1.05 1.07 1.12 1.08 1.02 1.04 1.06 1.04 1.01 1.02 1.03 1.01 1.00
```

モデルの行は、機構と合成をつなぎ、画面と同じ約 60 Hz で状態を渡して計算した（停止位置のずれは 0）。

- 当てはめの誤差（rms）は、線形の振動＋圧の山（0008 の形、0.4 秒分）で 0.114、ストッパーありで 0.096（0.4 秒分）、0.089（0.9 秒分）。
- 当てはめたモデルの θ を追うと、ストッパーに当たるのは最初の 1 回（46 ms）だけだった。跳ね返ったあとの揺れは、179 ms で重なり 0.976 まで戻る（1 回目は 0.998）。最初の 1 回でストッパーが勢いを吸い、その後は減衰の小さい揺れになる。これで 2 回目の山が 1 回目に近い高さになる。
- 2 回目の山は、0008 の 1.26 から 1.40 になった。映像の中央値（1.65）にはまだ届かないが、1 回ずつの立ち上がりでは 1.06〜1.48 とばらつく。
- 揺れは 0.6〜0.8 秒で収まる（0008 は 0.3〜0.4 秒）。映像の 0.4 秒より先の小さな山（約 330 ms・480 ms）とも合う。

## 結果

- `src/mechanism/simulation.ts`：`CoverParams.stopRestitution` を追加し、θ = 1 で跳ね返す。`coverOverlap` は θ をそのまま返す（0〜1）。
- `src/mechanism/simulation.test.ts`：最初の山がストッパーまで行くこと、2 回目の山が 1 回目の 0.95 倍以上で 110〜160 ms 後に来ること、0.8 秒で ±3% に収まること、ストッパーより先へ行かないことをテストした。
- `src/scene/scene.ts`：カバーはストッパーより先へは回らない（コメントのみ変更）。
